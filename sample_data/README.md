# Synthetic demo data

Both CSVs are generated by `scripts/generate_samples.py` using
`dataguard.demo.demo_dataset`, seed 42. All records represent fictional subscription
accounts. No source dataset, real customers, or third-party data is included.

Source: original programmatic data generation in this repository.
License: MIT, Copyright (c) 2026 Mohammed Alanazi (see [LICENSE](../LICENSE)).

The base generation creates 600 accounts with numerical, categorical, boolean,
datetime, and identifier columns. The classification target `churn` is a Bernoulli
draw from a logistic probability based on tenure, charges, and support tickets.
The regression target `annual_value` is a linear combination plus Gaussian noise.
These targets are pedagogical signals, not business or scientific claims.

The default derived demos intentionally inject:

- 48 missing charges and 25 missing plans (with possible overlap across columns).
- Three unusually large charges.
- A constant currency column and a near-constant legacy flag.
- An exact target copy, explicitly named `target_copy_review`, to exercise leakage review.
- Twelve duplicate rows, producing 612 total records.

These issues are synthetic modifications. Turning off the quality-issue toggle
produces the 600-row base generation. Even the base generation has an identifier
and datetime column, and natural statistical outlier candidates may exist.
